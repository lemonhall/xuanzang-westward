# 音频设计：西行·玄奘（先文案，后实现）

> 本轮只交付**设计文案**，不产生音频文件。实现路线（合成 / 采样库 / 采购）留待柠檬叔确认。

## 0. 总体原则

1. **一件乐器一个身份**：箫＝玄奘本人；鼓＝阻碍与时间；钟磬＝佛理与顿悟；人声＝苦难的重量。
2. **静比响更贵**：L2、L4 的重点是"稀疏"，让风声与呼吸成为主旋律。
3. **打击感靠三层**：每次命中同时给"高频击打点 + 中频体声 + 低频冲击"三层，缺一层就"不实"。
4. **音乐不参与 hitstop**：命中定格时音乐继续走，只把音效冻结在起音点上，制造"时间停了但世界还在"的感觉。

## 1. 总线与实现约定（供后续实现参考）

| 总线 | 内容 | 处理 |
|---|---|---|
| `Master` | 总输出 | 限制器，-1 dB 上限 |
| `Music` | BGM（可 2–3 条同步分层音轨） | 关卡状态切换时淡入淡出，段落同步 |
| `Ambience` | 环境底噪（风、水、雪、虫） | 常驻循环，随关卡区域交叉淡化 |
| `SFX` | 动作、命中、UI | 最多 16 并发，音高随机 ±3% |
| `Voice` | 梵呗、吟诵、叙事朗读（若制作） | 播放时对 `Music` 侧链压低 6 dB |

Godot 侧计划使用 `AudioStreamInteractive` 做 BGM 段落切换、`AudioStreamPlayer2D` 做空间化环境音、
`AudioStreamPlayer` 池化做音效，BGM 循环点在资源里标记（不靠脚本数拍子）。

## 2. 逐关设计

### L1 出关（长安 → 凉州）

- **BGM**：箫 + 古琴 + 手鼓，**76 BPM**，宫调五声。
  - 结构：`A 晨雾引子`（箫独奏 8 小节）→ `B 行进主题`（古琴拨弦 + 手鼓 16 小节循环）→ `C 关隘`（加入筚篥与低音战鼓，紧张）→ `D 出关`（笛主题 + 弦乐铺底，释然）。
  - 情绪曲线：静 → 走动 → 被拦 → 决意。
- **SFX（12 条）**：麻鞋踏土（轻/重两档）、起跳、落地（轻/重）、锡杖挥空（风声）、锡杖命中、佛珠拾取（玉磬短音）、火把噼啪、城门木轴、兵卒甲片摩擦、夜枭、度牒递出（纸与木）。
- **叙事音**：开场一句木鱼轻点，随后叙事卡出现。

### L2 流沙（莫贺延碛）

- **BGM**：筚篥 / 低音唢呐 + 大鼓 + 无词人声低吟，**60 BPM**，羽调。
  - 结构：`A 沙鸣`（长音噪层，几乎无旋律）→ `B 行板`（缓慢鼓点，四小节一循环）→ `C 干渴`（高频细鸣 + 心跳）→ `D 立誓`（人声由低吟转齐唱）。
  - 情绪曲线：荒 → 熬 → 濒死 → 立誓不退。
- **SFX（10 条）**：风沙呼啸（循环风噪）、沙粒击打（打击乐化）、水囊摇晃（最后一口水，声音要"空"）、沙暴预警（闷雷）、幻影低语（倒放人声）、枯骨风铃、心跳（随缺水加快）、耳鸣（高频细响）、干裂喘息、白骨踏碎。
- **特殊**：缺水后期把 `Ambience` 的高频逐步抬高、低频逐步抽掉，模拟"耳朵发闷"。

### L3 绝食（高昌故城）

- **BGM**：琵琶 + 筝 + 觱篥，**88 BPM**，商调。
  - 结构：`A 王庭`（华丽宫廷：觱篥 + 编钟 + 鼓）→ `B 挽留`（琵琶轮指密集）→ `C 枯坐`（只剩筝的单音与呼吸）→ `D 三日`（全静，只余钟磬一击）。
- **SFX（9 条）**：宫门沉重木轴、甲片推挤、食物托盘（瓷碗轻碰 + 油香"听不见但要有画面"）、水杯晃动、打坐呼吸（渐慢）、胃鸣、玉裂（定力受损）、绝食第三日耳鸣、众人跪拜的衣料摩擦。
- **规则音**：本关禁止攻击——按攻击键时播放"锡杖被按住"的闷响，替代打击音效。

### L4 凌山雪难（天山穆素尔岭）

- **BGM**：弦乐长音 + 低音鼓 + 无词人声，**52 BPM**，角调。
  - 结构：`A 风雪`（噪层 + 弦乐持续音）→ `B 攀行`（低音鼓每两小节一击）→ `C 冰裂`（不协和音程，突发打击）→ `D 沉默`（人声消失，只余风）。
- **SFX（10 条）**：踩雪（松/实两档）、冰面滑行、冰柱坠落（脆裂 + 低频轰鸣）、风雪呼啸、体温下降时的心跳变慢、同伴呼唤由近及远、牦牛铃、雪崩远景（长尾低频）、冻僵手指的关节声、合掌时的袖口摩擦。

### L5 恒河盗难

- **BGM**：塔布拉鼓 + 西塔琴 + 铜管，**110 → 60 BPM** 两段式。
  - 结构：`A 渡河`（西塔琴 + 水声）→ `B 盗至`（塔布拉鼓急促，110 BPM）→ `C 刀刃`（铜管与鼓同步重音）→ `D 天象`（鼓滚奏 + 钟磬 + 梵呗齐唱，60 BPM）。
- **SFX（11 条）**：河水、渡船木身吱嘎、刀风、刀击锡杖（金属撞击，游戏最"重"的一条）、扑击落地、诵经（木鱼 + 梵呗）、雷、骤雨、风起、兵器落地（忏悔）、众人受戒时的衣袍声。
- **打击感**：Boss 战要害命中给"金属 + 低频"双层，普通杂兵给"钝击 + 沙土"。

### L6 那烂陀辩经（曲女城无遮大会）

- **BGM**：钟磬 + 古琴 + 笛，**72 BPM**，宫调转羽调。
  - 结构：`A 晨钟`（钟磬一击开场）→ `B 诘难`（古琴断句、节奏渐密）→ `C 立论`（笛起、音区升高）→ `D 无遮`（全奏 + 钟磬齐鸣）。
- **SFX（10 条）**：寺院钟、磬、翻经页、念珠拨动、众僧低语（人群噪层）、竹简触碰（选择论点）、铜锣 + 短促鼓（破斥成功）、弦振（论锋弹幕）、火把燃烧、十八日终局的钟鸣与如潮掌声。
- **文斗音**：每次"立论 / 破斥 / 举证 / 静观"各有一个专属起音，玩家闭着眼也能听出自己做了什么。

### L7 归途译经

- **BGM**：古琴 + 箫 + 琵琶 + 童声无词合唱，**66 BPM**，宫调。
  - 结构：`A 归途`（行板，驮马节奏）→ `B 渡河`（琵琶轮指紧张段）→ `C 译经`（古琴 + 筝，夜灯）→ `D 圆寂`（箫独奏逐句减少音符，最后只余钟磬余响）。
- **SFX（10 条）**：驮马铃、经箱落地（纸页散落）、河水急流、灯芯爆响、毛笔书写、经卷翻页、笔搁、晚钟、心跳渐止、圆寂时的一记钟。
- **收束**：通关后音乐不停，续接 8 秒留白与一盏心灯的视觉收尾。

## 3. 通用音效规范

| 事件 | 层次与要求 |
|---|---|
| 命中 | 高频（击打点，3 ms 起音）+ 中频（体声）+ 低频（冲击，40–80 Hz）；三层同帧触发 |
| 受击 | 木鱼/闷鼓式短音 + 布料摩擦；音高随伤害下移 |
| 落地 | 依落地速度切换轻/重两档；重落地追加扬尘沙沙声 |
| 拾取 | 玉磬单音，音高随连续拾取逐级上行（最多五级） |
| 定力受损 | 铜锣闷响 + 心跳一击，画面配套震动 |
| UI | 一律短、干、无混响，避免与场景音效混淆 |
