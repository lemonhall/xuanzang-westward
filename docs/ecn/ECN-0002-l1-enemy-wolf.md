# ECN-0002：L1 敌人由「关吏」改为「北地苍狼」

## 基本信息

- **ECN 编号**：ECN-0002
- **关联 PRD**：PRD-0001（REQ-0001-007 关卡结构、REQ-0001-008 美术资产）
- **关联 Req ID**：REQ-0001-007、REQ-0001-008
- **发现阶段**：v1-level-01-and-flow 的施工中（敌兵美术生成被拒 + 用户实测反馈）
- **日期**：2026-09-22

## 变更原因

1. **美术通道受阻**：关吏定版图（`run-41-sheet_enemy_guardi_3`，持戟呼喝）被内容安全策略拒绝，A 方案不可用。
2. **玩法适配**：L1 是"潜行出关 + 荒野逃亡"，需要一个**横向移动、会扑击**的威胁；站桩官吏既难做，也不产生平台跳跃的压力。
3. **史实贴合**：凉州—瓜州—莫贺延碛一线本是北地苍狼的领地，狼作为野外威胁比"关吏"更贴故事。
4. **用户提出**："给人家生成个精灵图吧，是狼？"

## 变更内容

### 原设计

> L1 敌人：关吏（idle 2 / walk 4 / 阻喝 2，只推挤不掉血）；夜巡兵卒（idle 2 / walk 4 / 掷石 2）。

### 新设计

> L1 敌人：**北地苍狼**（idle 2 / 潜行 1 / 奔跑 1 / 跃扑 1 / 蜷坐受伤 1，巡逻 + 接触伤害，可被锡杖击退）。
> 关吏改为**仅叙事/文斗场景出现**（后续实现 REQ-0001-005 时再补美术）。
