# ECN-0001：人物一致性路线由"逐帧文生图"改为"定版图 + 参考图条件生成"

- **关联 Req ID**：REQ-0001-008
- **发现阶段**：v1-art-pipeline 的第 3 步（第一批素材生成后质检）
- **日期**：2026-09-22

## 变更原因

按原设计"每帧独立文生图"产出后，量化质检与人工目视都确认：**同一角色的不同帧不是同一个人**。

- 轮廓 IoU（相对概念图）：四帧中有一帧只有 0.260，其余 0.579–0.645；
- 色板 L1 差异约 0.25（约四分之一颜色质量不同）；
- 人工目视：脸型与五官明显不一致。

结论：文生图的身份一致性不足以支撑角色动画资产，必须改用条件生成。

## 变更内容

### 原设计

> 每个姿态一帧、独立调用 `/v1/images/generations`；靠固定"角色串"文本保证一致性；用 alpha 包围盒归一化解决几何对齐。

### 新设计

1. **定版图**：先用一次生成产出一张含 ≤5 个姿态的角色图，作为该角色的唯一身份参考。
2. **参考图条件生成**：其余姿态一律走 `POST /v1/images/edits`（multipart，`image=定版图`），并显式带 `background=transparent` 与 `size`，才能同时拿到人物一致性与透明底。
3. **一张图内的姿态数上限 5**：实测 6/12 个姿态会被内容安全策略拒绝（HTTP 400，不产生图片）。
4. **同图姿态之间必须完全不接触**：宽幅动作（挥杖）单独占行；否则切片无法分离（实测 5 列一行时中间几列互相重叠）。
5. **切片按 alpha 连通域**，不假设网格；归一化前做 alpha 下限（≤8 置 0）以避免帧高抖动。
