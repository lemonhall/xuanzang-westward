# 美术圣经：西行·玄奘（ART-BIBLE）

本文件是**唯一风格口径**。所有 OFOX 生图提示词都必须包含第 1 节的"风格串"，主角素材必须包含第 3 节的"角色串"。

## 0. 模型与一致性路线（硬规则）

1. **模型唯一**：所有生图一律使用 `openai/gpt-image-2.5-sunburst`，不混用其它模型（含 `openai/gpt-image-2`）。
2. **人物帧一律走参考图条件生成**：先定版一张概念图，之后每一帧都用 `POST /v1/images/edits`（multipart 上传该参考图）+ 文字描述"只改姿态、其余保持一致"。
   - 参考图编辑必须同时带 `background=transparent` 与显式 `size`，否则返回不透明图（实测：不带则得到 1254×1254 RGB）。
   - `input_fidelity` 对 2.5 不被支持（400），不要传。
3. 独立文生图**只用于无身份一致性问题**的资产：背景层、特效、道具、地形。
4. 敌人同样遵守第 2 条：先出该敌人的一张定版图，再以它为参考生成其余帧。
5. 每一批产出必须跑 `tools/consistency_check.py`，与参考图的轮廓 IoU 与色板差异要留档；离群帧重生成而不是凑用。
6. **一张图最多 5 个姿态**（实测 6/12 个必被内容安全策略拒绝）；同图姿态之间必须完全不接触，宽幅动作（挥杖）单独占一行，否则切片时无法分离。
7. 切片按 **alpha 连通域**（降采样→轻膨胀→连通域标注→按 y 间隙分行→行内按 x 排序），不得假设网格；归一化前先做 alpha 下限（≤8 置 0），否则帧高会抖动。

## 1. 风格串（STYLE GUARD，逐字使用）

```text
风格：中式国风美术，工笔重彩结合写意水墨；墨线匀净利落（线宽均匀、不脏不糊），设色淡雅克制，整体偏矿物颜料质感；光影柔和，边缘干净，适合作为 2D 横版游戏美术资产；画面内不出现任何文字、印章、落款、水印、边框、棋盘格。
```

## 2. 透明底规则（精灵图强制）

```text
背景：纯透明背景，真实 alpha 通道；主体以外的像素必须完全透明——没有地面、没有投影、没有环境景物、没有渐变底、没有灰白底、没有"画上去的透明格"。
```

## 3. 角色串（CHARACTER BLOCK，主角逐字使用）

```text
唐代高僧玄奘：面容清秀坚毅的中年僧人，光头，眉目沉静；身披赭黄与灰褐相间的百衲袈裟（补丁拼接清晰），内着交领僧袍，腰束布带；左手持九环锡杖（环饰分明），背竹编经笥（藤箱），脚穿麻鞋。比例约二点五头身，保留唐风衣褶与环饰细节。
```

## 4. 构图规则（精灵图）

```text
构图：人物全身完整入画，面向画面右侧的四分之三侧面；水平居中；头顶留白约百分之八，脚底留白约百分之八，双脚位于同一水平基线；四肢不与画面边缘相切。
```

> 几何一致性不依赖模型。所有产出必须经过 `tools/normalize_sprites.py`：
> **裁到 alpha 包围盒 → 按目标高度等比缩放 → 以"脚底基线 + 水平重心"对齐 → 贴入统一画布**。
> 这样即使每一张的取景略有差别，进引擎后帧与帧仍然对得齐。

## 8. 视差背景层清单（每关 4 层）

命名：`bg_<level>_<layer>.png`，layer ∈ `sky | far | mid | near`。

| 层 | 内容要求 | scroll_scale | 建议做法 |
|---|---|---|---|
| `sky` | 天穹/云气/日晕/极光，横向长卷，无地物 | 0.05 | 不透明，镜像平铺 |
| `far` | 远山/沙丘轮廓/雪岭，只有剪影与淡染 | 0.25 | 透明背景，镜像平铺 |
| `mid` | 城楼/佛塔/林带/寺院，可辨识地点 | 0.50 | 透明背景，镜像平铺 |
| `near` | 近景草丛/石岸/幡旗/枯枝，会遮住角色脚部 | 0.80 | 透明背景，放在角色图层之前 |

## 11. 提示词模板

### 11.1 单帧角色素材

```text
为 2D 横版平台跳跃游戏绘制**独立角色单帧素材**（不是场景、不是插画、不是设定页、不是多格拼图）：
{角色串}
动作：{动作描述}，第 {n} 帧，{姿态要点}。
{构图规则}
{透明底规则}
{风格串}
```

> 一帧一张图，而不是让模型画"4×2 拼图"。拼图模型的网格几乎不可能稳定对齐；
> 单帧 + 归一化管线才是可控做法。

### 11.2 视差背景层

```text
为 2D 横版平台跳跃游戏绘制**单张视差背景层**（横向长卷构图，画面中没有任何人物）：
地点与时间：{地点}，{时间与天气}。
本层内容：{该层元素}。若为 far/mid/near 层，请注意主体元素集中在画面中下部，上方留出大面积空白，便于游戏内叠加平台与角色。
构图：横向铺满，{地平线高度}，{留白要求}。
{透明底规则 或 "背景为不透明画面，无需透明"}（sky 层用后者）
{风格串}
```

### 11.3 特效素材

```text
为 2D 横版游戏绘制单个特效素材（单张，非拼图）：{特效描述}，纯透明背景，真实 alpha 通道，主体居中，四周完全透明，没有地面与投影，不要任何文字。
{风格串}
```

## 12. 质检清单（每批产出必过）

- [ ] `inspection-*.json` 存在，且 `mode` 含 `A`、`native_transparency` 为真（精灵图）。
- [ ] 透明像素占比 > 15%，主体 alpha 均值 > 200（`tools/check_assets.py` 输出）。
- [ ] 图片中不存在文字/印章/水印（人工目视，逐张记录）。
- [ ] 同角色同一动作的帧，经归一化后**包围盒高度一致**（脚本断言）。
- [ ] 光底/暗底各合成一次，剪影干净，无残留轮廓（脚本产出对照图）。
- [ ] 背景层为不透明、1024×1024、无人物、无文字。
