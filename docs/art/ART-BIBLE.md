# 美术圣经：西行·玄奘（ART-BIBLE）

本文件是**唯一风格口径**。所有 OFOX 生图提示词都必须包含第 1 节的"风格串"，主角素材必须包含第 3 节的"角色串"。

## 0. 模型与一致性路线（硬规则）

1. **模型分工（ECN-0003）**：**背景/场景/特效底图**用 `openai/gpt-image-2.5-sunburst`（真透明底可靠）；**所有精灵动画**用 `volcengine/doubao-seedream-5.0-pro`（2.5 对多姿态的安全策略误拦过多，不可用于动画）。Seedream 返回 RGB 无 alpha，且会把 1536×1024 放大到 2496×1664，因此精灵一律要求**纯品红 #FF00FF 平坦底**，再用 `tools/matte.py` 本地抠图（色度键控 + 颜色解混，不是阈值）。
2. **人物帧一律走参考图条件生成**：先定版一张概念图，之后每一帧都用 `POST /v1/images/edits`（multipart 上传该参考图）+ 文字描述"只改姿态、其余保持一致"。
   - 参考图编辑必须同时带 `background=transparent` 与显式 `size`，否则返回不透明图（实测：不带则得到 1254×1254 RGB）。
   - `input_fidelity` 对 2.5 不被支持（400），不要传。
3. 独立文生图**只用于无身份一致性问题**的资产：背景层、特效、道具、地形。
4. 敌人同样遵守第 2 条：先出该敌人的一张定版图，再以它为参考生成其余帧。
5. 每一批产出必须跑 `tools/consistency_check.py`，与参考图的轮廓 IoU 与色板差异要留档；离群帧重生成而不是凑用。
6. **一个角色一张图，姿态数不设 5 上限**（Seedream 接受 12 姿态总表，2.5 才必拒）；同图姿态之间必须完全不接触，宽幅动作（挥杖）单独占一行，否则切片时无法分离。
7. 切片按 **alpha 连通域**（降采样→轻膨胀→连通域标注→按 y 间隙分行→行内按 x 排序），不得假设网格；归一化前先做 alpha 下限（≤8 置 0），否则帧高会抖动。
7.1 **防忽大忽小（硬规则，ECN-0003）**：同一张图的所有帧共用**一个缩放比**（取中立姿态）；水平锚定用**脚/爪质心**、垂直锚定用**脚底基线**；**画布宁宽不缩**（玄奘 768×512、狼 512×384）——宽动作超框时加宽画布，而不是缩小姿态。机器闸门：`assets/qa/normalization-<actor>.json` 的 `unique_scales` 必须只有一个、`clamped` 必须为空（`normalize --verify` 断言）。
7.2 **抠图去噪（硬规则）**：纯品红底抠图必须两步走，缺一不可——
   `--alpha-floor 40`（α<40 判为全透明：这些是底色色差造成的雾点，面积过滤抓不到）＋ `--despill 0.85`（对半透明边缘做去溢色：品红键控的判据是 `min(r,g) > b`，把超出部分按强度拉回）＋ `--despeckle-min-area 64`（面积过小且与主体不连通的斑块整体清零，角色柔边属于大连通域故不受影响）。顺序固定：解混 → alpha 下限 → 去溢色 → 去斑。
   实测：只做面积过滤时低α像素 4171→3737（几乎无效）；加上 alpha 下限后，**可见品红像素降到 17 个（占画布 0.0004%）**。
7.4 **画布要比角色高**：画布高度不等于角色高度，而是"角色高度 + 高姿态余量"。玄奘角色 430 px、画布 1024×768、脚底基线 736——因为"锡杖上撩"这类姿态天生更高，画布不够高就会触发"缩到能放下"的钳制，直接破坏缩放比唯一性（实测出现 0.7619/0.77477 两个缩放比）。
   引擎侧换算规则：**屏幕尺寸由"角色在贴图里的高度"决定**（`ON_SCREEN_HEIGHT / TEXTURE_HEIGHT`），而不是画布高度；脚底对齐用 `offset.y = canvas_h/2 − baseline`。
7.5 **素材只能从"唯一来源"重建**：`assets/manifests/canonical.json` 登记每个角色的唯一来源图，`tools/rebuild_sprites.py` 负责①归档旧的派生资产②重新抠图/切片/归一化③跑闸门④**清空并重建 Godot 导入缓存**。任何历史 run 都不得再写入 `assets/sprites/`（`normalize` 已禁止覆盖已登记角色）。
7.6 **行走循环必须逐帧写明左右腿**：只写"迈步/交错"会让模型每帧都画同一条腿在前，动起来就是**滑步**（用户实测）。正确写法是逐帧指定：①右脚在前、左脚跟抬起 ②双腿并拢交接 ③左脚在前、右脚跟抬起 ④反向交接——至少 4 帧，且明确"四帧腿部位置必须明显不同、能看出左右交替"。
7.7 **切片必须按连通域隔离**，不能只按包围盒收紧：膨胀 padding 会把邻行/邻格的零星像素圈进来，收紧后就成了这一帧的残边（用户实测"横向切出上一行的残边"）。`_isolate_component` 在 padding 区域内从种子点做 flood fill，只保留与本姿态相连的像素。
7.8 **间距闸门的语义随实现更新**：自连通域隔离落地后，只有**接触/重叠**才是硬失败（两帧会并成一个连通域，由数量断言兜住），间隙小于 1% 图宽仅记警告。门槛的数值必须跟着实现的保证一起改，否则会拦下本来安全的图。
7.3 **姿态间距闸门**：同一行相邻姿态的水平间隙必须 ≥ 图宽 3%（`slice` 强制执行，低于阈值直接报错并给出重叠数值）。
   实测教训：狼图第一版三匹并排，包围盒水平**重叠 104px / 16px**，只是"没碰到"才切得开——这种图必须重做。正确做法是把版式写成几何约束（"每行两个姿态分别居中于左半/右半，中间留出 1/5 画面宽的纯色竖带"），而不是让模型自由排布。
8. **归一化的"稳定维度"按角色类型选**（否则会出现"一会儿大一会儿小"）：
   - 直立角色（玄奘）：用包围盒**高度**（待机/行走/跳跃高度接近），归一目标 430 px；
   - 四足动物（狼）：用包围盒**宽度＝体长**（潜行/跃扑高度差异巨大），归一目标 300 px；
   - 超画布时按 `min(目标缩放, 画布/基线可容纳缩放)` 钳制，保证永不溢出。
   实证：按高度归一时，狼的五帧高度被强行拉平，视觉上忽大忽小；改按体长归一后五帧体长统一 300 px，高度自然呈现 286/220/259/133/123（站立/跃扑/蜷坐/潜行/奔跑）。
9. **素材统一朝右绘制，游戏内靠 `flip_h` 镜像**（省一半生成量）；`Enemy` 每帧按巡逻方向设置 `flip_h`，并由 `tests/test_scene.gd::_test_enemy_art_and_facing` 断言"向左走时狼头必须朝左"。

## 1. 风格串（STYLE GUARD，逐字使用）

```text
风格：中式国风美术，工笔重彩结合写意水墨；墨线匀净利落（线宽均匀、不脏不糊），设色淡雅克制，整体偏矿物颜料质感；光影柔和，边缘干净，适合作为 2D 横版游戏美术资产；画面内不出现任何文字、印章、落款、水印、边框、棋盘格。
```

## 2. 透明底规则（精灵图强制）

```text
背景：纯透明背景，真实 alpha 通道；主体以外的像素必须完全透明——没有地面、没有投影、没有环境景物、没有渐变底、没有灰白底、没有"画上去的透明格"。
```

## 3. 角色串（CHARACTER BLOCK，主角逐字使用）

```text
唐代高僧玄奘：面容清秀坚毅的中年僧人，光头，眉目沉静；身披赭黄与灰褐相间的百衲袈裟（补丁拼接清晰），内着交领僧袍，腰束布带；左手持九环锡杖（环饰分明），背竹编经笥（藤箱），脚穿麻鞋。比例约二点五头身，保留唐风衣褶与环饰细节。
```

## 4. 构图规则（精灵图）

```text
构图：人物全身完整入画，面向画面右侧的四分之三侧面；水平居中；头顶留白约百分之八，脚底留白约百分之八，双脚位于同一水平基线；四肢不与画面边缘相切。
```

> 几何一致性不依赖模型。所有产出必须经过 `tools/normalize_sprites.py`：
> **裁到 alpha 包围盒 → 按目标高度等比缩放 → 以"脚底基线 + 水平重心"对齐 → 贴入统一画布**。
> 这样即使每一张的取景略有差别，进引擎后帧与帧仍然对得齐。

## 11. 提示词模板

### 11.1 单帧角色素材

```text
为 2D 横版平台跳跃游戏绘制**独立角色单帧素材**（不是场景、不是插画、不是设定页、不是多格拼图）：
{角色串}
动作：{动作描述}，第 {n} 帧，{姿态要点}。
{构图规则}
{透明底规则}
{风格串}
```

> 一帧一张图，而不是让模型画"4×2 拼图"。拼图模型的网格几乎不可能稳定对齐；
> 单帧 + 归一化管线才是可控做法。

### 11.2 视差背景层

```text
为 2D 横版平台跳跃游戏绘制**单张视差背景层**（横向长卷构图，画面中没有任何人物）：
地点与时间：{地点}，{时间与天气}。
本层内容：{该层元素}。若为 far/mid/near 层，请注意主体元素集中在画面中下部，上方留出大面积空白，便于游戏内叠加平台与角色。
构图：横向铺满，{地平线高度}，{留白要求}。
{透明底规则 或 "背景为不透明画面，无需透明"}（sky 层用后者）
{风格串}
```

### 11.3 特效素材

```text
{风格串}
```

## 12. 质检清单（每批产出必过）

- [ ] `inspection-*.json` 存在，且 `mode` 含 `A`、`native_transparency` 为真（精灵图）。
- [ ] 透明像素占比 > 15%，主体 alpha 均值 > 200（`tools/check_assets.py` 输出）。
- [ ] 图片中不存在文字/印章/水印（人工目视，逐张记录）。
- [ ] 同角色同一动作的帧，经归一化后**包围盒高度一致**（脚本断言）。
- [ ] 光底/暗底各合成一次，剪影干净，无残留轮廓（脚本产出对照图）。
- [ ] 背景层为不透明、1024×1024、无人物、无文字。
